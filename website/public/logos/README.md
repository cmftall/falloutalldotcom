## Manual Download Instructions for BNC Logo

The BNC logo needs to be manually downloaded:

1. **Option 1 - Official Source:**
   - Visit: https://www.nbc.ca/about-us/media.html
   - Look for "Media Kit" or "Logo Download"
   - Download PNG with transparent background
   - Save as: `bnc.png` in this directory

2. **Option 2 - Google Images:**
   - Search: "National Bank of Canada logo PNG transparent"
   - Filter: Transparent background, Large size
   - Download and save as: `bnc.png`

3. **Option 3 - LinkedIn:**
   - Visit National Bank of Canada's LinkedIn page
   - Right-click their logo → "Save Image As"
   - Convert to PNG with transparent background if needed
   - Save as: `bnc.png`

**Requirements:**
- Format: PNG
- Background: Transparent
- Size: 200-400px width recommended
- File size: < 50KB (optimize if larger)

The WorkedWith component will automatically show the logo once the file exists and is a valid PNG.
